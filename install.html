What a release contains

One archive per platform, a Windows installer, and a checksum file covering all of them.

WindowsOsanwe-Setup_<version>_windows_amd64.exe
osanwe-client_<version>_windows_amd64.zip
macOSosanwe-client_<version>_darwin_arm64.tar.gz
osanwe-client_<version>_darwin_amd64.tar.gz
Linuxosanwe-client_<version>_linux_amd64.tar.gz
ChecksumsSHA256SUMS

Take the arm64 build on an Apple Silicon Mac and amd64 on an Intel one. The Windows installer places the app for your user only and needs no administrator rights; the .zip is there for anyone who would rather not install anything.

Verify before you run it

This step is the point. A privacy client you downloaded without checking is a privacy client somebody else may have modified, and the digest costs one command.

macOS and Linux

cd ~/Downloads
sha256sum -c SHA256SUMS --ignore-missing

On macOS, shasum -a 256 -c SHA256SUMS --ignore-missing if sha256sum is absent.

Windows, in PowerShell

Get-FileHash .\Osanwe-Setup_<version>_windows_amd64.exe -Algorithm SHA256
Select-String -Path .\SHA256SUMS -Pattern 'Osanwe-Setup'

Compare the two by eye. They must match exactly.

If a digest does not match, stop. Do not run the file, and say so on the repository's issue tracker. A mismatch is either a broken download or a substituted one, and neither is worth guessing about.

Then run it

Extract the archive, put the osanwe.json your inviter sent you beside the programs, and start the launcher. It asks for the relay secret with the terminal echo off, so a pasted value is never shown, written to disk, or placed on a command line.

tar -xzf osanwe-client_<version>_linux_amd64.tar.gz
cd osanwe-client_<version>_linux_amd64
./start-osanwe.sh

On macOS, double-click Start Osanwe.command. On Windows, run the installer and open Osanwë from the Start Menu, or double-click Start Osanwe.cmd in the extracted folder.

The client opens a local window. It listens only on 127.0.0.1 and refuses to bind anything else, so nothing on your network can reach it.

The binaries are not code-signed yet. Windows SmartScreen and macOS Gatekeeper will warn you. Do not click through that warning unless the digest above matched and the invitation came through the channel you expected. Paid signing is deliberately outside the beta budget, and the warning is the honest consequence.

Building from source instead

Every release is reproducible from the repository, and today it is the only route. Go 1.26 or newer is required.

git clone https://github.com/EzraStone/Osanwe
cd Osanwe
./demo/ui.sh

That starts the whole stack locally — a stand-in provider, a mint, a gateway, a relay and the client — generates its own keys, and opens the window. Ctrl-C stops everything and deletes the keys it made. No invitation or gateway of your own is needed.

What this beta is not

Free, invited, text-only, and unsuitable for medical, legal, financial, employment, school, children's or vulnerable-source data. The gateway can currently read prompt and answer text; attested execution is not built. A separately operated relay is an experimental condition rather than a proven guarantee, and the client cannot prove operator independence.

The beta charter states the entry conditions in full, including the ones that are not yet met.
